# Bernardo Game Launcher

Modern Android emulator frontend with a clean and futuristic interface.

## Features

* Supports multiple emulators
* Modern dark UI
* Fast game launcher
* Automatic ROM scanner
* Favorites system
* Recent games
* Console categories

## Supported Consoles

* NES
* SNES
* Game Boy Advance
* Nintendo DS
* Nintendo 64
* PSP
* PlayStation 1
* PlayStation 2

## Emulators Used

| Console | Emulator          |
| ------- | ----------------- |
| NES     | NES.emu           |
| SNES    | Snes9x            |
| GBA     | mGBA              |
| NDS     | MelonDS           |
| PSP     | PPSSPP            |
| PS1     | DuckStation       |
| PS2     | NetherSX2 / PCSX2 |

## Technologies

* Kotlin
* Android Studio
* RecyclerView
* Material Design 3
* Glide
* Room Database
